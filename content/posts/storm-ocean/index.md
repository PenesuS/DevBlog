# Storm Ocean Shader

## Overview

This project focuses on developing a large-scale storm ocean
shader using Unreal Engine.

The goal is to create realistic ocean waves without
expensive real-time fluid simulation.

## Development Goals

- Large and irregular ocean waves
- World Position Offset (WPO)
- Procedural foam generation
- Performance optimization

## Development Progress

The first stage focuses on generating the main wave shapes.
